1) Extension page injection (HTML/XSS risk)

This section renders the query parameter ?dvceMsg=.... In vulnerable mode it uses innerHTML (unsafe). In fixed mode it uses textContent (safe).

2) Insecure storage demo (don’t store secrets)

Extensions often store tokens in chrome.storage. If your extension is compromised, attackers can read it. Use a fake value here.

3) Permissions demo (what extension pages can do)

This shows that extension pages can call privileged APIs. Here we fetch the active tab URL/title (requires tabs permission).

4) CSP demo (eval should be blocked)

A strict CSP makes it harder to turn HTML injection into full script execution. This button tries eval("2+2") and reports what happens.

5) Supply-chain simulation (dependency code runs with your privileges)

This page loads a “vendor library” from the extension package. In the real world, this could be an npm dependency. If the dependency is compromised, it runs with the same extension privileges.
