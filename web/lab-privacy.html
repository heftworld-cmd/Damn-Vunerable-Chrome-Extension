Lab: Data exfiltration & tracking abuse

Malicious (or compromised) extensions often abuse permissions + content scripts to collect data (URLs, page content, form inputs) and send it to a remote server.

Key idea
If an extension can read data (tabs/DOM/cookies) and can send data (network requests), then compromise can become a privacy breach.

This page asks DVCE for the active tab URL and title (requires the tabs permission).



    
What real attackers do

    
    
      
  • Collect browsing history / URLs, including sensitive query params.
    • 
      
  • Capture form fields and keystrokes via content scripts.
    • 
      
  • Inject ads or phishing overlays into pages.
    • 
      
  • Send data to a command-and-control (C2) endpoint.
    • 
    


    
How to secure

    
    
      
  • Minimize permissions and host access (<all_urls> is a big risk multiplier).
    • 
      
  • Don’t collect data you don’t need; avoid logging sensitive URLs/tokens.
    • 
      
  • Protect extension pages from XSS; lock down messaging bridges.
    • 
      
  • Review outbound network access; pin domains and validate payloads.
